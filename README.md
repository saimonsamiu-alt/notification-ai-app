# নোটিফিকেশন AI অ্যাপ — ফেজ ১ (MVP)

Email + Telegram থেকে মেসেজ টেনে জরুরি/না জরুরি ফিল্টার করে দেখায়। সব ফ্রি, ওপেন-সোর্স টুল দিয়ে বানানো — কোনো paid API লাগে না।

## সেটআপ (প্রথমবার)

1. Python ৩.১০+ ইনস্টল থাকতে হবে। চেক করো:
   ```
   python --version
   ```
   না থাকলে https://www.python.org/downloads/ থেকে ইনস্টল করো।

2. এই ফোল্ডারে এসে ডিপেন্ডেন্সি ইনস্টল করো:
   ```
   pip install -r requirements.txt
   ```

3. `.env.example` ফাইলটা কপি করে `.env` নামে সেভ করো, তারপর ভেতরে নিজের Email/Telegram তথ্য বসাও (নির্দেশনা `.env.example`-এর ভেতরেই আছে)।

4. চালাও:
   ```
   python -m notification_agent.main
   ```

## ফেজ ২ — লোকাল AI (ঐচ্ছিক, কিন্তু রেকমেন্ডেড)

স্মার্ট ক্লাসিফিকেশনের জন্য (শুধু কিওয়ার্ড না, মেসেজের মানে বুঝে):

1. https://ollama.com থেকে Ollama ইনস্টল করো (ফ্রি, ওপেন-সোর্স)
2. টার্মিনালে চালাও: `ollama pull llama3.2:3b` (ছোট মডেল, RTX 4050-এ আরামে চলবে)
3. Ollama ইনস্টল করলে এমনিতেই ব্যাকগ্রাউন্ডে চালু থাকে — আলাদা করে কিছু করা লাগবে না

Ollama ইনস্টল করা না থাকলেও অ্যাপ বন্ধ হবে না — নিজে থেকেই আগের rule-based (keyword) filter ব্যবহার করবে।

## যা হবে

- প্রতি ৬০ সেকেন্ডে নতুন অপঠিত ইমেইল আর Telegram মেসেজ চেক করবে
- Ollama চালু থাকলে LLM দিয়ে, না থাকলে VIP sender/কিওয়ার্ড দিয়ে "জরুরি" মার্ক করবে
- টার্মিনালে সহজ টেক্সট আকারে রেজাল্ট দেখাবে

- অটো-রিপ্লাই + ফাইন-টিউনিং লার্নিং লুপ
